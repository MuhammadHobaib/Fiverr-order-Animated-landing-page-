# JobOppFlyer Landing Page

A simple one-page HTML/CSS landing page for JobOppFlyer. Built with plain HTML, CSS, and a small bit of JS/meta-redirect — no frameworks, no build step.



## What it does

- Shows the JobOppFlyer flyer content (headline, offer, photo, contact info)
- Every link/button on the page points to the final destination:
  `https://jobopp.com/aj4693`
- The page also auto-forwards visitors to that same URL 4 seconds after it loads (via the `<meta http-equiv="refresh">` tag in `<head>`)

## How to change things

Final destination URL: search the file for `jobopp.com/aj4693` and replace every occurrence (there are 5: 3 links, the meta refresh tag, and the mailto stays as is).
